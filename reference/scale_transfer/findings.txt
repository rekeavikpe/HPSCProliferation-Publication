Interpretation limits
This is prediction without refitting, but it is retrospective internal evaluation: model structures, bounds, initial-state assumptions and P50 choice existed after analysis of all data. It is not an untouched external validation experiment. Using all-free training also differs from the documented three-fixed-parameter manuscript fit. Small test size, unresolved C4 aggregate day labels and unknown experimental batches limit interpretation. Test error bars are between-vessel SD, not prediction intervals. R² describes five daily condition means and is not an identifiability measure. No model is reranked using test errors. Model 0 is an a priori reference only.

Day-zero glucose is an allowed measured input from the 500-mL experiment. Fresh glucose is assumed equal to that initial value; lactate starts at 0 and aggregate diameter at 15 µm. These conditional prediction assumptions must accompany any claim.

Manuscript/response draft
We performed a retrospective scale-transfer evaluation by estimating all kinetic parameters from the five 100-mL conditions and selecting Model 5 by training-data BIC among seven distinct candidates. We then simulated the 500-mL condition using its vessel-specific P50 hydrodynamic inputs, feeding protocol and specified initial conditions, without refitting to later-time outcomes. State-specific prediction errors are reported separately from calibration errors. Because the model family and analysis settings were developed with prior access to the dataset, this analysis is not presented as independent external validation.

The C4/C5 contrast remains unresolved
At day 5, C4 aggregate size is predicted as 257.47 µm versus 261.83 µm observed. However, C5 remains underpredicted within training: 253.25 µm versus 330.82 µm. The predicted C5−C4 contrast is -4.22 µm versus 68.99 µm observed. Thus the favorable C4 transfer error does not resolve the between-vessel contrast or establish general scale-up accuracy.
